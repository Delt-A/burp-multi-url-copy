Copies the URLs of every selected table row to the clipboard — in Burp's own tables, and in tables drawn by other extensions.

Burp's native tables let you select many rows, but getting their URLs out one by one is slow. Third-party extension tables are worse: an extension's results grid may support multi-row selection and still offer no way to copy anything at all, because Burp only routes context-menu events to components it owns. A tester who wants to feed thirty endpoints from an Auth Analyzer run into ffuf or nuclei ends up retyping them.

This extension closes that gap with three ways in, all feeding the same four output formats.

How to use it

  • Burp's own tables — select rows, right-click, Copy URLs, pick a format. This path reads the URL straight off the request, so it never guesses.
  • Any other table — select rows and press Ctrl+Alt+U. The format is the default chosen in the Copy URLs tab.
  • Any other table, by right-click — a Copy URLs submenu is appended to whatever menu that table already shows. A table with no menu of its own gets a standalone one.

Output formats

  • Full URL — one per line, ready for ffuf -w or nuclei -l
  • Full URL (dedup) — duplicates removed, first-occurrence order kept
  • METHOD + URL — the method kept as a stable first column for awk or cut
  • Path only — scheme and host dropped

Partial results are always flagged

Reading a table that another extension drew is necessarily a heuristic: the extension reads that table's public model and nothing else — no reflection into another extension's internals. When some selected rows yield no URL, it copies what it recognized and says so, for example copied 12/15 - 3 rows had no recognizable URL, in the Copy URLs tab and in Burp's output log. When it recognizes nothing at all, the clipboard is left untouched, so a failed attempt never destroys what you had there. The full copied text is always shown in the tab, so you can check it before pasting it into a scanner.

A short list that looked complete would be the worst possible outcome here — the missing endpoint simply never gets tested — so a partial copy is never reported as a plain success.

Settings

  • The hotkey is configurable, and persists with your Burp preferences. The default avoids Ctrl+U and Ctrl+Shift+U, which Burp binds to URL encode and decode.
  • The default format used by the hotkey is configurable.
  • The last copy's full text and status are shown in the tab.
