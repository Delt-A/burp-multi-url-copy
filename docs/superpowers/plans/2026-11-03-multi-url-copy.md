# Multi URL Copy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Burp Suite extension that copies the URLs of every selected table row to the clipboard, working both in Burp's own tables and in tables drawn by other extensions such as Auth Analyzer.

**Architecture:** Two trigger paths feed one formatting pipeline. Burp's own tables go through a Montoya `ContextMenuItemsProvider`, which reads exact URLs from `HttpRequestResponse`. Every other table goes through a global Swing `KeyEventDispatcher` bound to `Ctrl+Alt+U`, which finds the focused `JTable` and scrapes its `TableModel` heuristically. All pure logic (`UrlEntry`, `UrlFormatter`, `TableScraper`, `CopyOutcome`, `Hotkey`) lives in `core` with no Burp dependency and is unit tested.

**Tech Stack:** Java 17 (source/target) on OpenJDK 25, Gradle 9.8.2 wrapper, Montoya API 2026.7 (`compileOnly`), JUnit 5, Swing.

**Spec:** `docs/superpowers/specs/2026-11-03-multi-url-copy-design.md`

## Global Constraints

- Java `release = 17`. Montoya publishes a Java 17 variant only.
- Gradle wrapper pinned to **9.8.2**. Gradle 8.5 cannot run a daemon on Java 25.
- Montoya `net.portswigger.burp.extensions:montoya-api:2026.7`, scope `compileOnly`. Lower than the installed Burp Suite Pro 2026.10.1, so every method is present at runtime.
- No shadow/fat jar. The extension has zero runtime dependencies; the plain `jar` task is the deliverable.
- `options.encoding = 'UTF-8'` on all compile tasks.
- All user-visible strings in **English**.
- Root package `multiurlcopy`.
- Default hotkey `Ctrl+Alt+U`. `Ctrl+U` and `Ctrl+Shift+U` are taken by Burp's URL encode/decode and must never be used.
- Do **not** use Montoya's `UserInterface.registerHotKeyHandler`. Its `HotKeyContext` enum covers only five Burp-native surfaces (`HTTP_MESSAGE_EDITOR`, `PROXY_HTTP_HISTORY`, `INTRUDER_ATTACK_RESULTS`, `ORGANIZER_ENTRIES`, `SITE_MAP_CONTENTS_TABLE`) and cannot reach an extension's table. A `KeyEventDispatcher` also consumes the key press before Burp sees it, so registering both would leave the Burp handler dead or fire two copies.
- Default ports (`443` for https, `80` for http) are omitted from rendered URLs; any other port is kept.
- Percent-encoding in source data is preserved verbatim. Never re-encode or decode.
- A partial copy is never reported as a plain success. `entries.size() + failedRows` always equals the number of selected rows.
- The clipboard is never overwritten when zero URLs were recognized.

```java
package multiurlcopy.core;

import java.util.ArrayList;
import java.util.LinkedHashSet;
import java.util.List;

/**
 * Renders {@link UrlEntry} values into the text that lands on the clipboard.
 *
 * <p>Nothing here re-encodes or decodes: whatever percent-encoding the
 * source carried is passed through untouched, so a copied URL is the URL
 * that was actually requested.
 */
public final class UrlFormatter {

    private UrlFormatter() {
    }

    public static String format(List<UrlEntry> entries, UrlFormat format) {
        List<String> lines = new ArrayList<>(entries.size());
        for (UrlEntry entry : entries) {
            lines.add(renderLine(entry, format));
        }
        if (format == UrlFormat.FULL_URL_DEDUP) {
            lines = new ArrayList<>(new LinkedHashSet<>(lines));
        }
        return String.join("\n", lines);
    }

    /** {@code scheme://host[:port]/path[?query]}, default ports omitted. */
    public static String fullUrl(UrlEntry entry) {
        StringBuilder out = new StringBuilder();
        out.append(entry.scheme()).append("://").append(entry.host());
        if (!isDefaultPort(entry.scheme(), entry.port())) {
            out.append(':').append(entry.port());
        }
        return out.append(pathAndQuery(entry)).toString();
    }

    private static String renderLine(UrlEntry entry, UrlFormat format) {
        return switch (format) {
            case FULL_URL, FULL_URL_DEDUP -> fullUrl(entry);
            case METHOD_AND_URL -> method(entry) + " " + fullUrl(entry);
            case PATH_ONLY -> pathAndQuery(entry);
        };
    }

    private static String method(UrlEntry entry) {
        String method = entry.method();
        return (method == null || method.isBlank()) ? "-" : method.trim();
    }

    private static String pathAndQuery(UrlEntry entry) {
        String path = entry.path();
        if (path == null || path.isEmpty()) {
            path = "/";
        }
        String query = entry.query();
        return (query == null || query.isEmpty()) ? path : path + "?" + query;
    }

    private static boolean isDefaultPort(String scheme, int port) {
        if (port == UrlEntry.NO_PORT) {
            return true;
        }
        return ("https".equalsIgnoreCase(scheme) && port == 443)
                || ("http".equalsIgnoreCase(scheme) && port == 80);
    }
}
```

```java
package multiurlcopy.core;

import java.net.URI;
import java.util.Optional;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * Turns an absolute http(s) URL string into a {@link UrlEntry}.
 *
 * <p>Parsing goes through the raw accessors of {@link URI} so that
 * percent-encoding survives untouched; {@code getPath()} would decode it
 * and hand back a URL that was never requested.
 */
public final class UrlParser {

    private static final Pattern EMBEDDED_URL = Pattern.compile("https?://\\S+");

    private UrlParser() {
    }

    /** Parses {@code url} when the whole string is an absolute http(s) URL. */
    public static Optional<UrlEntry> parse(String url, String method) {
        if (url == null || url.isBlank()) {
            return Optional.empty();
        }
        String trimmed = url.trim();
        URI uri;
        try {
            uri = new URI(trimmed);
        } catch (Exception e) {
            return Optional.empty();
        }
        String scheme = uri.getScheme();
        if (scheme == null || !(scheme.equalsIgnoreCase("http") || scheme.equalsIgnoreCase("https"))) {
            return Optional.empty();
        }
        String host = uri.getHost();
        if (host == null || host.isEmpty()) {
            return Optional.empty();
        }
        String path = uri.getRawPath();
        if (path == null || path.isEmpty()) {
            path = "/";
        }
        return Optional.of(new UrlEntry(
                method, scheme.toLowerCase(), host, uri.getPort(), path, uri.getRawQuery()));
    }

    /** Finds the first http(s) URL embedded anywhere in {@code text}. */
    public static Optional<UrlEntry> findFirst(String text) {
        if (text == null) {
            return Optional.empty();
        }
        Matcher matcher = EMBEDDED_URL.matcher(text);
        return matcher.find() ? parse(matcher.group(), null) : Optional.empty();
    }
}
```

Note: `URI.getPort()` already returns `-1` when no port is present, which
is exactly `UrlEntry.NO_PORT`.

```java
package multiurlcopy.core;

import javax.swing.JTable;
import javax.swing.table.TableModel;
import java.util.ArrayList;
import java.util.List;
import java.util.Optional;

/**
 * Reads URLs out of an arbitrary {@link JTable}, including tables drawn
 * by other Burp extensions, which Burp's own context menu never reaches.
 *
 * <p>Only the public {@link TableModel} is touched — no reflection into
 * another extension's internals — so anything this class can read is
 * also visible on screen.
 */
public final class TableScraper {

    private TableScraper() {
    }

    public static ScrapeResult scrape(JTable table) {
        int[] viewRows = table.getSelectedRows();
        TableModel model = table.getModel();
        List<UrlEntry> entries = new ArrayList<>(viewRows.length);
        int failed = 0;

        for (int viewRow : viewRows) {
            int modelRow = table.convertRowIndexToModel(viewRow);
            Optional<UrlEntry> entry = scrapeRow(model, modelRow);
            if (entry.isPresent()) {
                entries.add(entry.get());
            } else {
                failed++;
            }
        }
        return new ScrapeResult(List.copyOf(entries), failed);
    }

    private static Optional<UrlEntry> scrapeRow(TableModel model, int row) {
        int columns = model.getColumnCount();
        String[] values = new String[columns];
        for (int c = 0; c < columns; c++) {
            Object value = model.getValueAt(row, c);
            values[c] = value == null ? "" : value.toString().trim();
        }

        String method = valueOfColumn(model, values, "method");

        // Rule 2: a cell that is itself an absolute URL.
        for (String value : values) {
            Optional<UrlEntry> parsed = UrlParser.parse(value, method);
            if (parsed.isPresent()) {
                return parsed;
            }
        }

        // Rule 3: a host column joined with a path column.
        Optional<UrlEntry> joined = joinHostAndPath(model, values, method);
        if (joined.isPresent()) {
            return joined;
        }

        // Rule 4: a URL embedded inside a longer cell.
        for (String value : values) {
            Optional<UrlEntry> found = UrlParser.findFirst(value);
            if (found.isPresent()) {
                UrlEntry e = found.get();
                return Optional.of(new UrlEntry(method, e.scheme(), e.host(), e.port(), e.path(), e.query()));
            }
        }
        return Optional.empty();
    }

    private static Optional<UrlEntry> joinHostAndPath(TableModel model, String[] values, String method) {
        String host = valueOfColumn(model, values, "host");
        if (host == null || host.isEmpty()) {
            return Optional.empty();
        }
        String path = firstNonEmpty(
                valueOfColumn(model, values, "path"),
                valueOfColumn(model, values, "url"));
        if (path == null || !path.startsWith("/")) {
            return Optional.empty();
        }

        int port = parsePort(valueOfColumn(model, values, "port"));
        String scheme = port == 80 ? "http" : "https";

        int queryStart = path.indexOf('?');
        String query = queryStart < 0 ? null : path.substring(queryStart + 1);
        String pathOnly = queryStart < 0 ? path : path.substring(0, queryStart);

        return Optional.of(new UrlEntry(method, scheme, host, port, pathOnly, query));
    }

    /** Value of the first column whose name contains {@code needle}, case-insensitively. */
    private static String valueOfColumn(TableModel model, String[] values, String needle) {
        for (int c = 0; c < values.length; c++) {
            String name = model.getColumnName(c);
            if (name != null && name.toLowerCase().contains(needle)) {
                return values[c];
            }
        }
        return null;
    }

    private static String firstNonEmpty(String... candidates) {
        for (String candidate : candidates) {
            if (candidate != null && !candidate.isEmpty()) {
                return candidate;
            }
        }
        return null;
    }

    private static int parsePort(String raw) {
        if (raw == null || raw.isEmpty()) {
            return UrlEntry.NO_PORT;
        }
        try {
            return Integer.parseInt(raw);
        } catch (NumberFormatException e) {
            return UrlEntry.NO_PORT;
        }
    }
}
```

```java
package multiurlcopy.core;

/**
 * The result of one copy attempt, and the single place that decides how
 * it is announced.
 *
 * <p>Scraping a foreign table is a heuristic and can drop rows. A short
 * list that looks complete is worse than no feature at all — the missing
 * endpoint never gets tested — so a partial copy is never rendered as a
 * plain success, and a copy that recognized nothing never touches the
 * clipboard.
 */
public record CopyOutcome(String payload, int copied, int total, String reason) {

    public static CopyOutcome of(String payload, int copied, int total) {
        return new CopyOutcome(payload, copied, total, null);
    }

    public static CopyOutcome nothingSelected() {
        return new CopyOutcome("", 0, 0, "no rows selected");
    }

    public static CopyOutcome noTableFocused() {
        return new CopyOutcome("", 0, 0, "no table focused");
    }

    /** False whenever nothing was recognized, so an existing clipboard survives. */
    public boolean shouldWriteClipboard() {
        return copied > 0;
    }

    public boolean isPartial() {
        return copied > 0 && copied < total;
    }

    public String statusLine() {
        if (reason != null) {
            return "nothing copied - " + reason;
        }
        if (copied == 0) {
            return "nothing copied - none of the " + total + " selected rows had a recognizable URL";
        }
        if (isPartial()) {
            int failed = total - copied;
            return "copied " + copied + "/" + total + " - " + failed
                    + (failed == 1 ? " row had" : " rows had") + " no recognizable URL";
        }
        return "copied " + copied + (copied == 1 ? " URL" : " URLs");
    }
}
```

```java
package multiurlcopy.core;

import java.awt.event.InputEvent;
import java.awt.event.KeyEvent;

/**
 * A modifier + key combination, stored as a string in Burp's preferences
 * and matched against live {@link KeyEvent}s.
 *
 * <p>The default is {@code Ctrl+Alt+U}: Burp already binds {@code Ctrl+U}
 * and {@code Ctrl+Shift+U} to URL encode and decode.
 */
public record Hotkey(int modifiers, int keyCode) {

    private static final int DEFAULT_MODIFIERS = InputEvent.CTRL_DOWN_MASK | InputEvent.ALT_DOWN_MASK;

    public static Hotkey defaultHotkey() {
        return new Hotkey(DEFAULT_MODIFIERS, KeyEvent.VK_U);
    }

    /** Parses {@code "Ctrl+Alt+U"}; anything unrecognized yields the default. */
    public static Hotkey parse(String text) {
        if (text == null || text.isBlank()) {
            return defaultHotkey();
        }
        int modifiers = 0;
        int keyCode = -1;
        for (String rawPart : text.split("\\+")) {
            String part = rawPart.trim();
            if (part.isEmpty()) {
                continue;
            }
            switch (part.toLowerCase()) {
                case "ctrl", "control" -> modifiers |= InputEvent.CTRL_DOWN_MASK;
                case "alt" -> modifiers |= InputEvent.ALT_DOWN_MASK;
                case "shift" -> modifiers |= InputEvent.SHIFT_DOWN_MASK;
                case "meta", "cmd", "super" -> modifiers |= InputEvent.META_DOWN_MASK;
                default -> keyCode = keyCodeOf(part);
            }
        }
        return (keyCode == -1 || modifiers == 0) ? defaultHotkey() : new Hotkey(modifiers, keyCode);
    }

    public String display() {
        StringBuilder out = new StringBuilder();
        if ((modifiers & InputEvent.CTRL_DOWN_MASK) != 0) {
            out.append("Ctrl+");
        }
        if ((modifiers & InputEvent.ALT_DOWN_MASK) != 0) {
            out.append("Alt+");
        }
        if ((modifiers & InputEvent.SHIFT_DOWN_MASK) != 0) {
            out.append("Shift+");
        }
        if ((modifiers & InputEvent.META_DOWN_MASK) != 0) {
            out.append("Meta+");
        }
        return out.append(KeyEvent.getKeyText(keyCode)).toString();
    }

    /**
     * True only for a key-press of exactly this combination. An extra held
     * modifier is a different shortcut and must not trigger a copy.
     */
    public boolean matches(KeyEvent event) {
        if (event.getID() != KeyEvent.KEY_PRESSED) {
            return false;
        }
        int relevant = InputEvent.CTRL_DOWN_MASK | InputEvent.ALT_DOWN_MASK
                | InputEvent.SHIFT_DOWN_MASK | InputEvent.META_DOWN_MASK;
        return event.getKeyCode() == keyCode && (event.getModifiersEx() & relevant) == modifiers;
    }

    private static int keyCodeOf(String part) {
        if (part.length() == 1) {
            char c = Character.toUpperCase(part.charAt(0));
            if (c >= 'A' && c <= 'Z') {
                return KeyEvent.VK_A + (c - 'A');
            }
            if (c >= '0' && c <= '9') {
                return KeyEvent.VK_0 + (c - '0');
            }
        }
        return -1;
    }
}
```

```java
package multiurlcopy.ui;

import burp.api.montoya.persistence.Preferences;
import multiurlcopy.core.Hotkey;
import multiurlcopy.core.UrlFormat;

/** Extension settings, persisted in Burp's own preference store. */
public class Settings {

    private static final String KEY_HOTKEY = "multiurlcopy.hotkey";
    private static final String KEY_FORMAT = "multiurlcopy.format";

    private final Preferences preferences;

    public Settings(Preferences preferences) {
        this.preferences = preferences;
    }

    public Hotkey hotkey() {
        return Hotkey.parse(preferences.getString(KEY_HOTKEY));
    }

    public void setHotkey(Hotkey hotkey) {
        preferences.setString(KEY_HOTKEY, hotkey.display());
    }

    public UrlFormat defaultFormat() {
        String stored = preferences.getString(KEY_FORMAT);
        if (stored == null) {
            return UrlFormat.FULL_URL;
        }
        try {
            return UrlFormat.valueOf(stored);
        } catch (IllegalArgumentException e) {
            return UrlFormat.FULL_URL;
        }
    }

    public void setDefaultFormat(UrlFormat format) {
        preferences.setString(KEY_FORMAT, format.name());
    }
}
```

```java
import burp.api.montoya.http.message.requests.HttpRequest;

import burp.api.montoya.ui.contextmenu.ContextMenuItemsProvider;
import multiurlcopy.core.CopyOutcome;
import multiurlcopy.core.CopyReporter;
import multiurlcopy.core.CopyService;
import multiurlcopy.core.UrlEntry;
import multiurlcopy.core.UrlFormat;
import multiurlcopy.core.UrlFormatter;
import multiurlcopy.core.UrlParser;

import javax.swing.JMenu;
import javax.swing.JMenuItem;
import java.awt.Component;
import java.util.ArrayList;
import java.util.List;

/**
 * Adds a "Copy URLs" submenu to Burp's own tables.
 *
 * <p>This path never guesses: the URL comes straight from the request, so
 * every selected row yields exactly one entry.
 */
public class CopyUrlsContextMenu implements ContextMenuItemsProvider {

    private final CopyReporter reporter;

    public CopyUrlsContextMenu(CopyReporter reporter) {
        this.reporter = reporter;
    }

    @Override
    public List<Component> provideMenuItems(ContextMenuEvent event) {
        List<HttpRequestResponse> selected = event.selectedRequestResponses();
        if (selected.isEmpty()) {
            return List.of();
        }

        JMenu menu = new JMenu("Copy URLs");
        for (UrlFormat format : UrlFormat.values()) {
            JMenuItem item = new JMenuItem(format.displayName());
            item.addActionListener(e -> copy(selected, format));
            menu.add(item);
        }
        return List.of(menu);
    }

    private void copy(List<HttpRequestResponse> selected, UrlFormat format) {
        List<UrlEntry> entries = new ArrayList<>(selected.size());
        for (HttpRequestResponse item : selected) {
            HttpRequest request = item.request();
            UrlParser.parse(request.url(), request.method()).ifPresent(entries::add);
        }
        String payload = UrlFormatter.format(entries, format);
        CopyService.perform(CopyOutcome.of(payload, entries.size(), selected.size()), reporter);
    }
}
```

```java
package multiurlcopy.burp;

import multiurlcopy.core.CopyOutcome;
import multiurlcopy.core.CopyReporter;
import multiurlcopy.core.CopyService;
import multiurlcopy.core.ScrapeResult;
import multiurlcopy.core.TableScraper;
import multiurlcopy.core.UrlFormatter;
import multiurlcopy.ui.Settings;

import javax.swing.JTable;
import javax.swing.SwingUtilities;
import java.awt.Component;
import java.awt.KeyEventDispatcher;
import java.awt.KeyboardFocusManager;
import java.awt.event.KeyEvent;

/**
 * The path into tables Burp does not own.
 *
 * <p>Burp routes context-menu events only to its own components, so an
 * extension's {@link JTable} is unreachable that way. A focus-manager
 * dispatcher reaches all of them.
 */
public class HotkeyDispatcher implements KeyEventDispatcher {

    private final Settings settings;
    private final CopyReporter reporter;

    public HotkeyDispatcher(Settings settings, CopyReporter reporter) {
        this.settings = settings;
        this.reporter = reporter;
    }

    @Override
    public boolean dispatchKeyEvent(KeyEvent event) {
        if (!settings.hotkey().matches(event)) {
            return false;
        }

        JTable table = enclosingTable(event.getComponent());
        if (table == null) {
            CopyService.perform(CopyOutcome.noTableFocused(), reporter);
            return true;
        }

        ScrapeResult result = TableScraper.scrape(table);
        if (result.total() == 0) {
            CopyService.perform(CopyOutcome.nothingSelected(), reporter);
            return true;
        }

        String payload = UrlFormatter.format(result.entries(), settings.defaultFormat());
        CopyService.perform(CopyOutcome.of(payload, result.entries().size(), result.total()), reporter);
        return true;
    }

    private static JTable enclosingTable(Component start) {
        Component component = start != null
                ? start
                : KeyboardFocusManager.getCurrentKeyboardFocusManager().getFocusOwner();
        while (component != null) {
            if (component instanceof JTable table) {
                return table;
            }
            component = component.getParent();
        }
        return null;
    }

    /** Registers this dispatcher; returns a runnable that removes it again. */
    public Runnable register() {
        KeyboardFocusManager manager = KeyboardFocusManager.getCurrentKeyboardFocusManager();
        SwingUtilities.invokeLater(() -> manager.addKeyEventDispatcher(this));
        return () -> SwingUtilities.invokeLater(() -> manager.removeKeyEventDispatcher(this));
    }
}
```

The dispatcher returns `true` — consuming the event — only when the
hotkey actually matched, so every other Burp binding keeps working.

```java
package multiurlcopy.burp;

import burp.api.montoya.BurpExtension;
import burp.api.montoya.MontoyaApi;
import multiurlcopy.ui.Settings;
import multiurlcopy.ui.SettingsTab;

public class MultiUrlCopyExtension implements BurpExtension {

    @Override
    public void initialize(MontoyaApi api) {
        api.extension().setName("Multi URL Copy");

        Settings settings = new Settings(api.persistence().preferences());
        SettingsTab tab = new SettingsTab(settings, api.logging());

        api.userInterface().registerSuiteTab("Copy URLs", tab);
        api.userInterface().registerContextMenuItemsProvider(new CopyUrlsContextMenu(tab));

        Runnable unregisterHotkey = new HotkeyDispatcher(settings, tab).register();
        api.extension().registerUnloadingHandler(unregisterHotkey::run);

        api.logging().logToOutput(
                "Multi URL Copy loaded. Hotkey: " + settings.hotkey().display()
                        + " (works in other extensions' tables too).");
    }
}
```

A `KeyEventDispatcher` outlives an extension reload unless it is removed,
so the unloading handler is required, not optional — without it, a reload
leaves a stale dispatcher holding the old classloader.

```markdown
# Multi URL Copy

A Burp Suite extension that copies the URLs of every selected table row
to the clipboard — in Burp's own tables and in tables drawn by other
extensions such as Auth Analyzer.

## Why the hotkey exists

Burp routes context-menu events only to components it owns. An
extension's table is plain Swing, so a registered
`ContextMenuItemsProvider` is never called there. The global hotkey
reaches those tables by reading the focused `JTable`'s public model.

## Use

- **Burp's own tables** — select rows, right-click, **Copy URLs**, pick a
  format.
- **Any other table** — select rows, press **Ctrl+Alt+U**. The format is
  the default chosen in the **Copy URLs** tab.

Formats: `Full URL`, `Full URL (dedup)`, `METHOD + URL`, `Path only`.

## Partial results are always flagged

Scraping a foreign table is a heuristic. When some selected rows yield no
URL, the extension copies what it recognized and says so —
`copied 12/15 - 3 rows had no recognizable URL` — in the Copy URLs tab
and in Burp's output log. When it recognizes nothing, the clipboard is
left untouched. The full copied text is always shown in the tab so it can
be checked before it is pasted into a scanner.

## Build

Requires a JDK 17 or newer; the build compiles with `release = 17`
because that is what the Montoya API targets.

    ./gradlew clean build

Output: `build/libs/multi-url-copy.jar`. Load it in Burp via
Extensions → Installed → Add → Java.
```

**Spec coverage.** Every spec section maps to a task: the six units to
Tasks 1–9; the two data flows to Tasks 9 (context menu) and 9 (hotkey);
the four formats to Task 2; the five scraper rules to Task 4; the honesty
contract to Tasks 5, 7 and 8; the hotkey choice to Task 6; the settings

and 7. The spec's "out of scope" list is matched by the absence of any
task touching bodies, file export, reflection, or curl/ffuf formats.

One spec deviation, deliberate: the spec names five core units, this plan
has seven (`UrlParser`, `CopyService`/`CopyReporter` split out). The split
keeps "what is a URL string" separate from "which cell holds one", and
"who announces a copy" separate from "what a copy produced" — both are
testable alone and fail for different reasons.

**Type consistency.** `UrlEntry.NO_PORT` is used identically in Tasks 1,
2, 3 and 4. `UrlFormatter.format(List, UrlFormat)` and
`UrlFormatter.fullUrl(UrlEntry)` are called with those exact signatures in
Tasks 3, 4, 9. `ScrapeResult.entries()/failedRows()/total()` match between
Tasks 4 and 9. `CopyOutcome.of/nothingSelected/noTableFocused/
shouldWriteClipboard/isPartial/statusLine/payload` match between Tasks 5,
7, 8 and 9. `Hotkey.parse/display/matches/defaultHotkey` match between
Tasks 6, 8 and 9. `Settings.hotkey/setHotkey/defaultFormat/setDefaultFormat`
match between Tasks 8 and 9. `CopyReporter.report` is implemented by
`SettingsTab` in Task 8 and consumed in Task 9.

**Known risk, carried deliberately.** `UrlParser.parse` uses
`java.net.URI`, which rejects some URLs a browser accepts — an unencoded
space or a literal `|` in a query, for example. Those rows land in
`failedRows` and are therefore *reported*, never silently dropped. If
real traffic shows this firing often, the fix is a regex fallback inside
`UrlParser.parse`; it is not worth building before the failure is
observed.
